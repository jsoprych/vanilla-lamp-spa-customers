# Customer Management SPA

A lightweight customer management application built with TypeScript, ES modules, PHP, and SQLite.

## Core Technologies
- **Frontend (Development)**: TypeScript
- **Frontend (Runtime)**: JavaScript (ES modules, bundled)
- **Backend**: PHP 8.3 (OOP, no frameworks)
- **Database**: SQLite
- **Build Tool**: esbuild (minimal bundler)
